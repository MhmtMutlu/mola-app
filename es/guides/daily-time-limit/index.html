Cómo poner un límite de tiempo diario a una app

Para poner un límite de tiempo diario a una app en el iPhone, ve a Ajustes > Tiempo de uso > Límites de uso de apps > Añadir límite: elige la app y fija el tiempo. Cuando el tiempo se cumple, la app queda bloqueada el resto del día.

Paso a paso con Tiempo de uso

  1. Abre Ajustes > Tiempo de uso > Límites de uso de apps y toca Añadir límite.
  2. Elige una categoría (por ejemplo, Redes sociales) o apps concretas dentro de una categoría.
  3. Fija el tiempo diario. Con Personalizar días puedes dar otro tiempo a los fines de semana.
  4. Para activar Bloquear al finalizar el límite, primero tienes que definir un código de Tiempo de uso.

El tiempo lo cuenta iOS y, con Compartir entre dispositivos activado, se cuenta en conjunto en los dispositivos que usan la misma cuenta de Apple.

Con Mola

  1. Crea un nuevo límite diario en la pestaña Hoy.
  2. Elige las apps y fija el tiempo diario.
  3. Elige el nivel de exigencia.

Cuando el tiempo se cumple, esas apps se bloquean; las demás siguen abiertas. Si el nivel de exigencia del límite lo permite, puedes tomarte un descanso de 5 minutos. El tiempo lo sigue contando iOS: Mola no ve qué app usas ni durante cuánto tiempo; solo recibe el aviso de que el tiempo se ha cumplido.

¿Un límite de tiempo o un horario?

  • Un límite diario significa «voy a usar esta app, pero solo este tiempo al día». Va bien para las redes sociales y los juegos.
  • Un horario significa «que no se abra durante estas horas». Va bien para las horas de trabajo, de estudio y de sueño.

Los dos se pueden usar a la vez: un límite diario para el día y un plan de sueño para la noche.

Preguntas habituales

¿El límite se reinicia a medianoche? Sí. El tiempo diario empieza de nuevo cada día.

¿Cuántos minutos elijo? No hay una única respuesta correcta. Mirar tu media semanal en Tiempo de uso y elegir un poco menos es un comienzo que puedes mantener.
