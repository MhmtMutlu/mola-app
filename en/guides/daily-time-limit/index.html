How to set a daily time limit for an app

To set a daily time limit for an app on iPhone, go to Settings > Screen Time > App Limits > Add Limit: choose the app and set the time. When the time is up, the app is blocked for the rest of the day.

Step by step with Screen Time

  1. Open Settings > Screen Time > App Limits and tap Add Limit.
  2. Choose a category (Social, for example) or individual apps inside a category.
  3. Set the daily time. With Customize Days you can give weekends a different amount.
  4. To turn on Block at End of Limit, you first need to set a Screen Time passcode.

iOS counts the time. With Share Across Devices turned on, the time is combined across all devices signed in to the same Apple Account.

With Mola

  1. Create a new daily limit in the Today tab.
  2. Choose the apps and set the daily time.
  3. Choose the strictness level.

When the time is up, those apps are blocked; your other apps stay open. If the limit's strictness level allows it, you can take a 5-minute break. iOS still does the counting: Mola doesn't see which app you use or for how long; it's only told when the time is up.

A time limit or a schedule?

  • A daily limit means "I'll use this app, but only this much a day". It suits social media and games.
  • A schedule means "not at all during these hours". It suits work, study and sleep hours.

The two can be used together: a daily limit for the day and a sleep plan for the night.

Common questions

Does the limit reset at midnight? Yes. The daily time starts again every day.

How many minutes should I choose? There is no single right answer. A good place to start is your weekly average in Screen Time: pick a little less than that.
